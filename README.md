# 🐍 Snake Moderno

Juego clásico de **Snake** desarrollado con **HTML, CSS y JavaScript**, con un diseño moderno, sistema de puntuación, niveles y dificultad progresiva.

## 🎮 Características

* 🐍 Juego clásico de Snake.
* 🎯 Sistema de puntuación.
* 📈 Sistema de niveles.
* ⚡ La velocidad aumenta conforme avanzas de nivel.
* 💀 Detección de Game Over.
* 🔊 Efectos de sonido.
* 🎨 Interfaz moderna con efectos visuales.
* 📱 Diseño sencillo y ligero.

## 🕹️ Controles

Utiliza las **flechas del teclado** para controlar la serpiente:

| Tecla | Acción          |
| ----- | --------------- |
| ⬆️    | Mover arriba    |
| ⬇️    | Mover abajo     |
| ⬅️    | Mover izquierda |
| ➡️    | Mover derecha   |

## 📊 Sistema de niveles

Cada vez que consigues **5 puntos**, avanzas un nivel y la velocidad del juego aumenta.

La dificultad se incrementa progresivamente para hacer que el juego sea más desafiante.

## 🚀 Cómo ejecutar

No necesitas instalar dependencias.

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en tu navegador.
4. ¡Comienza a jugar! 🐍

También puedes utilizar **Live Server** en Visual Studio Code para ejecutarlo localmente.

## 🎯 Objetivo

Consigue la mayor puntuación posible comiendo la comida y evitando chocar contra las paredes o contra tu propia serpiente.
